# Function

## Synchronus dan Asynchronus

Program dimulai dari sebuah function bernama Queue() yang menerima 2 parameter yaitu second dan name, didalamnya terdapat function wait yang memiliki program error handling menggunakan switch case dimana tipe dari parameter second harus valid dan program selanjutnya merupkan built-in function timer yaitu setTimeOut() dimana akan melakukan program mengembalikan nama lewat parameter resolve() dan program akan dijalankan setelah waktu tunggunya selesai.

Setelah semua progam selesai dijalankan, function wait() dikembalikan lewat new Promise() yang nantinya akan diproses saat pemanggilan Queue() menggunakan then-catch maupun async-await.
